# SurfLK - Your Complete Beach Experience

A modern, responsive website for SurfLK - offering surf lessons, hostel accommodation, restaurant, photography, and comprehensive beach vacation packages in Sri Lanka.

## 🌊 Features

- **Modern & Responsive Design** - Optimized for mobile, tablet, and desktop
- **Complete Service Showcase** - Surf lessons, accommodation, dining, photography, and more
- **Package Display** - Day packs, combo stays, and group packages
- **Interactive Menu** - Categorized food menu with breakfast, lunch, dinner, and drinks
- **Contact Form** - Easy inquiry system for bookings
- **Smooth Animations** - Professional transitions and hover effects
- **SEO Optimized** - Meta tags and descriptions included

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ installed on your system
- npm package manager

### Installation & Running

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npx vite
```

3. Open your browser and visit: `http://localhost:5173`

## 📱 Responsive Design

The website is fully responsive and tested on:
- **Mobile devices** (320px - 480px)
- **Tablets** (481px - 1024px)
- **Desktops** (1025px+)

## 🎨 Customization Guide

### 1. Update Contact Information
- Edit `src/components/Contact.jsx` - Phone, email, location
- Edit `src/components/Footer.jsx` - Footer contact details

### 2. Add Real Images
- Replace placeholders in `src/components/Gallery.jsx`
- Add your surf spot photos

### 3. Connect Booking Platform
- Update form submission in `src/components/Contact.jsx`
- Integrate with your third-party booking system

### 4. Update Menu Items
- Edit `src/components/Menu.jsx` - Food items and prices

### 5. Update Package Details
- Edit `src/components/Packages.jsx` - Package info and pricing

## 🏗️ Build for Production

```bash
npm run build
```

Files will be in the `dist` folder, ready for deployment.

## 🌐 Deployment

Deploy to Netlify, Vercel, GitHub Pages, or any web hosting service by uploading the `dist` folder.
